# BalkansCoast26 (Obsidian Vault)

This repository is an Obsidian vault for a June 2026 Balkans coast trip, focused on Karst geology from Montenegro to Slovenia.

## Open in Obsidian

1. Clone or download this repository.
2. Open Obsidian.
3. Select **Open folder as vault**.
4. Choose the folder where you cloned this repository.

## Purpose

- Keep trip notes organized in Markdown.
- Track locations, field observations, and references.
- Maintain a versioned history of vault updates with Git.

## Notes

- This vault is plain Markdown and works without paid Obsidian features.
- Commit changes regularly to keep travel notes and edits in sync.
